# 🏥 MedSaaS - Sistema de Agendamento Médico (Desenvolvendo)

> 🚀 **Status:** Fase 3 Concluída (Frontend, Fluxo de Agendamento e Dashboard Admin)

## 📖 Sobre o Projeto
O **MedSaaS** é um Software as a Service (SaaS) construído do zero, focado na gestão de agendamentos para clínicas médicas. O projeto conta com uma interface imersiva para o paciente e um **Painel Administrativo** para a gestão da clínica.

Este projeto foi construído aplicando princípios de **Engenharia de Software**, Padrões de Projeto e Clean Code.

## ✨ Funcionalidades Implementadas
-[x] **Infraestrutura Docker:** Servidores web e banco de dados isolados em containers.
- [x] **Segurança PDO:** Proteção nativa contra SQL Injection usando Prepared Statements e padrão Singleton.
- [x] **Algoritmo de Disponibilidade:** O sistema cruza a jornada de trabalho do médico com os horários já ocupados no banco e retorna apenas os "slots" livres.
- [x] **Frontend Imersivo (Glassmorphism):** Tela de agendamento de alto padrão focada em conversão e UX.
- [x] **Dashboard Administrativo:** Rota segura para a clínica visualizar todos os pacientes agendados no dia.
